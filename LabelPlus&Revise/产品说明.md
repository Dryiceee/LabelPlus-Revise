# LabelPlus&Revise 1.0

完整版本，包含原 LabelPlus 的浏览、Label、录入、审校，以及 Revise 返修标注和 Photoshop 导入。原“LabelPlus QC / LabelPlus+Revise”完整版本统一更名为 **LabelPlus&Revise**。日期：2026-11-02。

## 软件

完整解压后运行 `LabelPlus&Revise.exe`，保留同目录 `LabelPlus&Revise.exe.config`、`Lang` 和 `labelplus_config.xml` 等资源。需要 Windows 10/11 与 .NET Framework 4.8。

F6 进入监修，选择成品目录后自动匹配同级 `images` 原图目录；左键从箭头尾部拖向问题位置，右侧填写说明，保存为 `revise.txt`。F7 在同一画布切换原图/成品。

滚轮上下移动，Ctrl＋滚轮左右移动，Alt＋滚轮缩放，空格＋左键抓手拖动。监修画布保留右键/中键平移；说明编辑框内正常输入空格，Ctrl＋Enter 返回画布。

## Photoshop

在“文件 → 脚本 → 浏览”运行 `PS-Script/LabelPlus&Revise.jsx`，可选择译文导入或返修导入。只用返修导入时，也可运行 `PS-Script/LabelPlus&Revise_Revise.jsx`。

返修导入自动匹配返修单同目录的 `output`，按同名 PSD 批量生成普通像素图层 `revise`。仅打开有问题的页面，旧 revise 改名并隐藏；不自动保存或关闭 PSD，正常结束不弹总结窗口。返修绘制沿用已修复分辨率换算及工作路径保护的实现。

原有译文导入需要脚本旁的 `ps_script_res` 文件夹，请保留。

## 命名与兼容

窗口标题、程序文件、程序集产品信息、PS 脚本标题和入口文件均使用新名称。旧版下载包仍保留。返修单继续采用 `LabelPlus-QC 1` 格式，已有文件无需转换，内部命名空间和上游版权归属保留。

名称中的 `&` 是文件名的一部分。双击运行即可；命令行中请完整引用路径，例如 PowerShell 使用 `& '.\LabelPlus&Revise.exe'`。包内“打开示例.cmd”已处理引号。
