# LabelPlus&Revise / LabelRevise 构建说明

两个版本均使用原来的 .NET Framework 4.8 WinForms 桌面与 TypeScript/ExtendScript 实现。更名只调整公开品牌、程序及脚本文件名称；命名空间 LabelPlus 和返修单格式 LabelPlus-QC 1 保留。

## LabelPlus&Revise 完整源码包

- `Desktop/LabelPlus&Revise.sln` 为完整桌面解决方案。
- 在 Visual Studio 开发者 PowerShell 中运行 `Desktop/Build-QC.ps1`。
- 输出 `Desktop/LabelPlus/bin/Release/LabelPlus&Revise.exe` 及同名 `.exe.config`，并保留运行资源。
- Photoshop 目录运行 `npm ci`，再运行 `build.ps1`。
- PS 输出 `build/LabelPlus&Revise.jsx`、`build/LabelPlus&Revise_Revise.jsx` 及 `ps_script_res`。

完整版返修核心与 LabelRevise 0.6.1 一致，包含高分辨率路径坐标换算及工作路径备份恢复；原有译文导入入口保留。

## LabelRevise 独立源码包

- `Desktop/LabelRevise.csproj` 只编译返修工作区及独立窗口。
- 在 Photoshop 目录运行 `npm ci`，随后在源码根目录运行 `Build-Revise.ps1`。
- 输出 `Desktop/bin/Release/LabelRevise.exe`、同名 `.exe.config`、`build/LabelRevise.jsx`。

两个构建脚本均支持便携编译工具参数。历史 BUILD.md 和上游 README 保留代码来源；以本说明中的新文件名为准。

## 本工作区

桌面编译器位于 `work/roslyn/tasks/net472`，.NET 4.8 引用程序集根位于 `work/net48-refs/build`。TypeScript 和 Photoshop 类型声明可复用 `work/PS-Script-1.7.4/node_modules`。

更名后旧程序集哈希记录作为历史资料保留；本次打包校验使用各包内“版本与校验.json”。含 `&` 的路径在 PowerShell 或批处理里需要加引号。
