# LabelRevise 1.0

仅保留返修标注与 Photoshop 返修导入。原“LabelPlus Revise”独立版本统一更名为 **LabelRevise**。日期：2026-11-02。

## 软件

完整解压后运行 `LabelRevise.exe`，启动即进入返修界面。请保留旁边的 `LabelRevise.exe.config`，以启用高 DPI 清晰显示。需要 Windows 10/11 与 .NET Framework 4.8。

1. 点击“新建监修 / 成品目录”，选择成品图片文件夹。
2. 自动匹配同级 `images` 原图目录，找不到时手动选择。
3. 左键从说明位置拖向问题位置，松开处是箭头头部。右侧填写说明，保存为 `revise.txt`。
4. F7 切换原图和成品。滚轮上下移动，Ctrl＋滚轮左右移动，Alt＋滚轮缩放，空格＋左键抓手拖动。

点击“本页问题”项目后可直接输入。文字框内空格正常输入，Ctrl＋Enter 返回画布。Ctrl＋S 保存，Ctrl＋Shift＋S 另存为，Ctrl＋Z/Y 撤销/重做。

## Photoshop

在“文件 → 脚本 → 浏览”运行 `PS-Script/LabelRevise.jsx`。选择返修单后自动匹配同目录的 `output`，按图片与 PSD 的同名关系批量导入。

每页标注合并成一个普通像素 `revise` 图层。旧 revise 改名并隐藏；没有问题的 PSD 不主动打开。脚本不自动保存或关闭文档，正常完成不弹总结窗口。

## 命名与兼容

窗口标题、程序文件、程序集产品信息、PS 脚本标题和入口文件统一为 LabelRevise。现有编辑与导入逻辑保持不变，旧返修单可直接使用；内部 `LabelPlus-QC 1` 格式标识和上游版权声明保留。

本次更名完成重新编译及命名检查，没有重复运行此前的 Photoshop 流程测试。此前旧名称版本的测试记录保留为历史资料，不能作为本次新文件哈希的验证记录。源码和构建说明见 `源码.zip`。
