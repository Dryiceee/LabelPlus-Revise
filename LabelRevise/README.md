# LabelRevise 1.0

仅保留返修标注与 Photoshop 返修导入的独立版本。日期：2026-11-02。

0.6.1 补上 PS 路径坐标从像素到点的分辨率换算，修复高分辨率 PSD 中箭头偏移、超出画布或导入失败的问题；并在绘制前备份已有工作路径，完成后恢复其原始几何，避免 Photoshop 创建临时路径时覆盖它。

从现有 LabelPlus QC 删减而来，沿用原来的 Windows Forms 监修界面、画布、图片显示、问题编辑和返修单格式，以及 PS 0.5.1 的复合路径批量绘制。桌面的翻译工作区、原有四种模式、分组管理、译文录入/审校、翻译导出、语言切换和托盘功能均已移出本版本的源码及构建。PS 只保留一个直接导入入口，移除了模式选择、译文解析、译文导入及相关模板、xtools 等资源。

## 使用软件

完整解压后运行 `LabelRevise.exe`，启动即进入返修标注界面。运行需要 Windows 10/11 和 .NET Framework 4.8。请保留程序旁的 `LabelRevise.exe.config`，以启用高 DPI 清晰显示。

1. 点击“新建监修 / 成品目录”，选择嵌字完成的成品图片文件夹。
2. 自动匹配同级的 `images` 原图目录，也兼容成品目录里面的 `images`；找不到时提示手动选择。
3. 按住左键，从说明位置拖向问题位置后松开，松开处是箭头头部。
4. 在右侧填写问题；点击“本页问题”中的项目后可直接输入。说明框自动避让箭头，也可以手动拖动。
5. 保存返修单，默认文件名 `revise.txt`。

可以继续打开旧版 QC 的返修单，无需转换。换电脑后，可用“重定位成品目录”和“选择原图目录”调整路径。

## 快捷操作

- 滚轮上下移动；Ctrl＋滚轮左右移动；Alt＋滚轮缩放。
- 空格＋左键抓手拖动，也保留右键/中键平移。
- F7 在同一画布切换原图和成品，保留查看位置与缩放。
- Ctrl＋N 新建，Ctrl＋O 打开，Ctrl＋S 保存，Ctrl＋Shift＋S 另存为。
- 左右方向键或 PageUp/PageDown 翻页；Delete 删除选中问题。
- Ctrl＋Z 撤销，Ctrl＋Y 重做。
- 说明框内按键用于文字输入；Ctrl＋Enter 返回画布。

## Photoshop 导入

1. 在 Photoshop 选择“文件 → 脚本 → 浏览”，运行 `PS-Script/LabelRevise.jsx`。
2. 选择返修单，脚本自动选择返修单同目录下的 `output` 文件夹；找不到时手动选择 PSD 目录。
3. 检查同名文件对应关系，点击“生成 revise”。
4. 完成后直接返回 Photoshop，检查标注并手动保存。只有发生导入异常时才显示错误提示。

仅扫描所选目录当前这一层。图片与 PSD 按不含后缀的同名匹配，尺寸必须一致。没有问题的页面不主动打开，已打开的文档会复用。

每页标注合并为一个普通、透明的像素图层 `revise`。再次导入时，原有 `revise` 改名并隐藏。脚本不自动保存、不关闭任何 PSD，也不修改图片尺寸或原有图层内容。每页失败时尝试回退本页导入操作；回退失败会明确提示。

箭头和说明框使用复合路径批量填充；相交的项目按原问题顺序拆批，保持遮挡顺序。只清理脚本创建的临时路径。无需其他脚本或 `ps_script_res` 文件夹。

## 示例

双击 `打开示例.cmd`，或在软件中打开 `Sample/revise.txt`。第一页有两条问题，第二页没有问题。
